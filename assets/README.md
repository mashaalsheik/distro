# Assets

One folder per record ID, e.g. `assets/SW-001/` with `01.png`, `02.png`, … (or `source.mp4` for a video) and `contact-sheet.png`.

These files are not committed. They're mirrored to Google Drive:

- **Drive folder:** [distro-assets](https://drive.google.com/drive/folders/1ygNTESJMh-2Q3DY716b0nevJiNi029IZ)
- **Inbox:** [distro-assets/inbox](https://drive.google.com/drive/folders/1ZbQd7DwCxx6dUrwyZl0xueGQ1mABMXLe). Drop new reference videos and screenshots here. `/dos-collect` gives each one an `SW-###` ID, moves it into `distro-assets/SW-###/`, and puts that folder's link in the record's `drive` field.
